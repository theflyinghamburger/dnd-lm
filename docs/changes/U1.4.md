## Change brief

M4.7 added `sheet.attacks` and `sheet.spells` to `CharacterSheet`, and
`SheetPanel` renders neither: an imported wizard's spell list is invisible to
the player who imported it (FR-403, P1 half). `Chat` fetches the campaign
roster for `@` autocomplete and never shows it.

This adds an Attacks section (name, bonus as a click-to-roll button gated on
`mine`, damage), a Spells section grouped by level in native `<details>`, and
an "At the table" list in `Chat` from the roster query it already holds.
Web-only; the floor is `fast`, raised to `standard` to match the sibling U1
subtasks (user-visible behaviour).

## Specification

AC-1  `attackRoll(bonus)` returns `1d20+K` / `1d20-K` for every bonus the schema
      permits (-20..30), and each parses through `parseDiceExpression` — the
      grammar `resolveRollRequest` falls back to — to one d20 with modifier
      `bonus`. An attack with no stored bonus returns `null` and renders read-only.
AC-2  `spellsByLevel` returns levels ascending, omits empty levels, keeps sheet
      order within a level, and loses no spell at the 400-spell schema maximum.
AC-3  The Attacks section shows name, signed bonus and damage; the bonus button
      calls the existing `onRoll` and is `disabled` unless `mine`.
AC-4  The Spells section renders one `<details>` per non-empty level, `open` for
      cantrips and level 1 only, the summary naming the level and its count.
AC-5  A prepared spell carries a `●` glyph (aria-hidden) and visually-hidden
      ", prepared" text; nothing is carried by colour alone (NFR-403).
AC-6  No attacks reads "No attacks."; no spells reads "No spells." with no
      `<details>` rendered.
AC-7  `Chat` lists every roster member as display name, `@handle`, and a `.role`
      badge, from the existing `['roster', campaignId]` query; no new query.

## Decisions

- D-1  Pure logic tests only (epic #72, `pregen-picker.md` D-5): no DOM testing
  library. AC-1/AC-2 are unit-tested in `session/sheet-lists.test.ts`; AC-3..AC-7
  are markup, checked by reading and by hand.
- D-2  Attack rolls send the raw expression `1d20±K`, already in the dice
  grammar; no new named-roll format (the issue forbids growing the parser). The
  server therefore labels the roll with the expression, not the attack name.
  The stored bonus is the sheet's own, as the M4.7 importer keeps it.
- D-3  Damage stays display-only: it is free text ("1d8-2 Slashing") and the
  issue asks only for the bonus to roll.
- D-4  Spell detail fields (range, components, …) are not rendered; the issue
  asks for the grouped, prepared-marked list.
