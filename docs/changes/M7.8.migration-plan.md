# Migration plan — M7.8

`apps/api/drizzle/0008_clever_purifiers.sql`:

```sql
CREATE TYPE "public"."provider_connection_audit_action" AS ENUM
  ('created', 'updated', 'replaced_key', 'deleted', 'enabled', 'disabled');

CREATE TABLE "provider_connection_audit" (
  "id"             uuid PRIMARY KEY DEFAULT gen_random_uuid() NOT NULL,
  "connection_id"  uuid NOT NULL,
  "actor_user_id"  uuid,
  "action"         "provider_connection_audit_action" NOT NULL,
  "changed_fields" text[] DEFAULT '{}'::text[] NOT NULL,
  "at"             timestamp with time zone DEFAULT now() NOT NULL
);

ALTER TABLE "provider_connection_audit"
  ADD CONSTRAINT "provider_connection_audit_actor_user_id_users_id_fk"
  FOREIGN KEY ("actor_user_id") REFERENCES "public"."users"("id")
  ON DELETE set null ON UPDATE no action;

CREATE INDEX "provider_connection_audit_connection_idx"
  ON "provider_connection_audit" USING btree ("connection_id", "at");
```

**Shape.** A new table and a new enum. Nothing existing is altered, so no
rewrite, no lock on a table anything reads, and no backfill: history starts at
deploy. Rows written before this change simply have no audit trail, which is
true and better than a synthesised one.

**The missing foreign key on `connection_id` is deliberate**, not an oversight
in the generated SQL — see the work item's Decisions and the schema comment. An
audit row outlives the row it audits.

**Index.** `(connection_id, at)` serves the only query shape there is: one
connection's history in order. No index on `actor_user_id`; "everything this
admin did" is a rare operator question a sequential scan answers on a table this
size.

**Order.** Purely additive. The previous build does not know the table exists
and is unaffected; this build writes to it from the first mutation after deploy.

**Verification.** `pnpm db:migrate`, then `pnpm db:check` (CI runs the same
drift check). `apps/api/test/provider-audit.e2e.test.ts` asserts one row per
mutation type against live Postgres, and the M7.8 rollup query in
`dm-connections.e2e.test.ts` runs against the shape this migration leaves.
